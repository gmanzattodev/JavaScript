# 📚 Sobre

Este repositório contém meus estudos completos de **JavaScript aplicado ao Front-End**.

O objetivo é dominar JavaScript moderno criando aplicações reais, entendendo profundamente como a linguagem interage com HTML, CSS, APIs e o navegador.

Todo o conteúdo será desenvolvido na prática, utilizando projetos que simulam situações encontradas no mercado de trabalho.

---

# 🎯 Objetivos

Ao finalizar este repositório serei capaz de:

- Manipular o DOM
