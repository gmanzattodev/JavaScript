# 📚 Aula 05 - Formulários em JavaScript

## Sobre

Nesta aula aprendemos como criar e manipular formulários utilizando JavaScript, capturando dados, validando informações e controlando o envio do formulário.

## Conteúdo

- `<form>` → Agrupa os campos do formulário.
- `input.value` → Obtém ou altera o valor de um campo.
- `submit` → Evento executado ao enviar o formulário.
- `event.preventDefault()` → Impede o recarregamento da página.
- **Validação** → Verifica se os dados estão corretos antes do envio.
- `form.reset()` → Limpa todos os campos do formulário.
- `input.type` → Permite alternar entre `"password"` e `"text"`.

## Boas práticas

- Valide os dados antes de enviar.
- Exiba mensagens claras ao usuário.
- Destaque os campos com erro.
- Faça validações em tempo real quando possível.
- Sempre valide também no Back-End.

## Objetivo da aula

Ao final desta aula você será capaz de:

- Criar formulários.
- Capturar valores dos campos.
- Validar dados.
- Controlar o envio do formulário.
- Limpar os campos após o envio.
- Criar funcionalidades como **mostrar/ocultar senha**.
